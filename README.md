# Free to Talk — المكان بيحكي

تطبيق ويب للموبايل (PWA): رسائل مجهولة بتنزرع بالمكان اللي انكتبت فيه، وبتختفي بعد 24 ساعة هي وردودها. بدون أي حزم خارجية: Node.js 22 فقط (SQLite مدمجة).

## شو في بالنسخة الأولى
- **الشاشة الرئيسية**: الرسائل اللي حواليك (١ / ٢ / ٥ كم)، ترتيب حسب الأحدث أو الأقرب أو الأكثر تفاعلاً، وفلترة حسب التصنيف.
- **التصنيفات**: سؤال، تنبيه، مفقودات، عرض، دردشة.
- **رسالة جديدة**: نص لحد 280 حرف + صورة وحدة (بتنضغط على الموبايل وبتنمسح منها بيانات الموقع المخفية).
- **الردود**: أسماء مؤقتة داخل كل رسالة (صاحب الرسالة / مجهول ١ / مجهول ٢…)، وبتختفي مع الرسالة.
- **الحماية**: تقييم ↑↓، إبلاغ بأسباب (٣ بلاغات بتخفي الرسالة، و«تهديد أو خطر» بيخفيها فوراً)، حظر شخص، كلمات ممنوعة، حد للنشر، وتقييد اللي سمعته سلبية.
- **الخصوصية**: ما في أسماء ولا أرقام؛ كل جهاز إله هوية مخفية. موقع الرسالة بينحفظ مقرّب لمربع ~100 م، وموقعك وإنت بتتصفح ما بينحفظ أبداً.
- **بعد 24 ساعة**: الرسالة بتختفي عن الناس وصورتها بتنحذف. نسخة نصية مخفية بتضل 30 يوم للبلاغات الخطيرة وبعدها بتنمسح.
- **أماكن تجريبية**: البوليتكنك، وسط الخليل، البلدة القديمة — للتجربة بدون GPS (بتطفيها من اللوحة عند الإطلاق).

## لوحة التحكم `/admin`
إحصائيات اليوم، البلاغات والرسائل المخفية (إرجاع / حذف / إيقاف الكاتب)، آخر الرسائل، والإعدادات (مدة البقاء، حدود البلاغ والنشر، الكلمات الممنوعة).

## السيرفر
تركيب مرة واحدة:
```
curl -fsSL https://raw.githubusercontent.com/alshaheedlib-beep/free-to-talk/main/install.sh | bash
```
- التطبيق على المنفذ **8082**، وعلى `https://talk.alshaheed.ps` عبر Caddy بعد إضافة سجل A باسم `talk` يأشر على IP السيرفر.
- **ليش الرابط الآمن مهم؟** الموبايل ما بيعطي الموقع الحقيقي إلا على https. على `http://IP:8082` جرّب بالأماكن التجريبية.
- البيانات في `/opt/freetotalk-data` (تبقى مع كل تحديث). كلمة سر اللوحة في `/opt/freetotalk-data/admin-password.txt`.
- كل دقيقة بيفحص GitHub، وعند وجود تعديل بيبني التطبيق من جديد (السجل في `/var/log/free-to-talk-deploy.log`).

## محلياً
```
npm start   # http://localhost:3000  —  /admin  (كلمة السر: admin)
```
